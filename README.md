# CarePoint — Hospital Management System

Full-stack web app to manage hospital operations: doctors, patients, and appointments.

## Tech Stack
- **Frontend:** React, Vite, Lucide icons
- **Backend:** Django REST Framework
- **Database:** SQLite

## Features
- Dashboard with live counts (doctors, patients, appointments)
- CRUD for doctors, patients, and appointments
- Search and filter records
- Admin profile menu (top-right)
- In-app Help Center: Guide, FAQ, Support form
- Responsive hospital workspace UI
